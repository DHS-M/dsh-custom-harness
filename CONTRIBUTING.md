# Contributing

## Humans

1. Branch from `main`.
2. Put product changes under `harness/`.
3. Document in `harness/docs/changes/` (next number).
4. Add a note under `contributors/logs/` (see `TEMPLATE.md`).
5. Open a PR with summary and test steps.

## Agents

Follow **[AGENTS.md](./AGENTS.md)** strictly.

## Review focus

- Persistence paths on `/data`
- Plugin inject correctness
- No secrets in git
- Change log entry present
